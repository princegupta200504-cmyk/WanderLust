# ✈️ WanderLust – Travel & Hotel Booking Platform

**Live Demo:** [https://wanderlust-o3qd.onrender.com](https://wanderlust-o3qd.onrender.com)

**Created WanderLust**, a responsive Airbnb-style travel and hotel booking platform. It allows users to explore, book, and manage properties easily, while property owners can efficiently add and update listings.

## Key Achievements

- **Easy Onboarding:** Quickly add new resort and hotel properties.  
- **Manage Listings:** Add, edit, and maintain property details, amenities, and pricing.  
- **Responsive Design:** Works smoothly on desktop, tablet, and mobile.  
- **User-Friendly:** Provides a simple and seamless experience for users and property managers.

## Features

- Explore travel and hotel listings  
- User authentication (Sign Up / Login / Logout)  
- Add, edit, and manage properties  
- Upload property images  
- Search and filter listings  
- Fully deployed and live
